## Reporting a Vulnerability

If you discover a potential security vulnerability within `hypersae` (such as credential leaks, arbitrary code execution vulnerabilities in serialized weights, or unsafe dataset streaming loaders):

1. **Do NOT open a public issue.**
2. Send an email directly to **`vishal.verma@dehurdle.com`** describing:
   - The nature of the vulnerability.
   - Steps to reproduce or proof-of-concept payload.
   - Impact assessment.

We will acknowledge receipt within 24 hours and provide a timeline for vulnerability remediation and security patch releases.
